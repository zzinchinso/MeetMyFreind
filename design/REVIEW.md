## 제출 전 대화 동시 보관·제출 후 재진입 차단 (#15)
- D-01·D-04·P-04: 세션에 answers·photos까지 포함해 다민·정진 대화를 독립적으로 유지한다. 답변·기록·위치는 현재 탭 sessionStorage(`chinchinso-sessions`, 체험 모드는 `-demo`)에 저장하고 사진은 메모리에만 둔다. 새로고침 시 사진 이후 단계였다면 사진 단계로, 전체 확인 수정 중이었다면 전체 확인으로 되돌려 기록이 중복되지 않게 한다. 저장된 대화가 있으면 첫 화면 대신 주선자 목록으로 열리고 각 행에 '진행 중 · N/24'를 표시한다.
- 제출 성공 시 세션을 모두 지우고(`forgetSessions`) `submitted`가 참인 동안 form 화면 요청은 상태 화면으로 되돌린다. 목록·주선자 선택·이전 버튼도 잠긴다. 새로고침·앞으로가기 후에도 접수 확인 정보(sessionStorage)로 상태 화면이 열린다. 수정은 '내 정보 보기 → 수정하기'(토큰 기반 update)로만 가능하다.
- 320×568 브라우저: 다민 3턴 → 정진 새 대화(답변 비어 있음, 성별 공유) → 목록 '진행 중 · 3/24' → 새로고침 → 목록 복원 → 다민 재진입 4/2·기록 3개·이름 유지. 체험 모드 제출 → 접수 완료, 저장소 비움, `‹` 없음, startChat/강제 form 렌더가 상태 화면으로 귀결, 수정하기만 form 진입 확인.

## 말풍선 2줄 규칙 (#9)
- C-02: 주선자 일반 대화 말풍선을 빈 줄(\n\n) 기준으로 짧은 발화로 나누고 중복·긴 표현을 줄였다. 말풍선 안의 강제 줄바꿈(\n)은 없앴다.
- 320×568 브라우저에서 두 주선자 × 24개 차례 + 접수 완료·확인 중·확인 완료·진행 어려움 화면의 말풍선 117개를 실측: `(clientHeight - 상하 패딩) / line-height` 가 모두 2 이하. 말줄임·글자 축소 없음.
- 사용자 답변 말풍선과 전체 확인(review-bubble)·사진/동의 안내 상자는 이 규칙의 대상이 아니며 그대로 둔다.
- tests/flow.cjs에 같은 범위를 문자 수(≤30자, 줄바꿈 없음)로 검사하는 회귀 테스트를 추가했다.

## 친구 목록과 프로필 상세 검증
- C-09: 브라우저 실측 목록 행73px, 모바일 프레임393px 유지. 이름·상태 한 줄로 카드 높이 축소.
- 다민 프로필→상세→대화, 정진 이름→즉시 대화, 정진 프로필→목록 복귀 확인. 상세 열기만으로 주선자 답변을 변경하지 않는다.
- 상태문구는 좁은 폭에서 생략하고 상세에 전문 제공. 가짜 온라인·미읽음 표시 없음. 토큰 게이트 및 기존 전체 흐름 검사 통과.
- 상세 개선(#7): 아바타·이름·역할 → 첫 메시지 미리보기(실제 채팅 말풍선 구성 재사용) → 소속/주선 경험/이런 사람 라벨이 붙은 사실 목록(좌측 정렬 2열) → 자동 질문·직접 확인 안내 순으로 위계를 정리. 하단에 '목록으로'와 '{이름}과 대화하기'를 나란히 배치. 320×568과 393×852에서 렌더 확인, 프로필→목록, 프로필→대화(주선자 값 반영), 목록 행→즉시 대화 동작 확인. 새 주장(경력·소속)은 추가하지 않고 기존 문구만 재배치.

C-11 건너뛰기 강조(#12): 선택형·입력형 선택 질문 모두에서 건너뛰기를 composer 메타의 작은 글자 버튼 대신 입력창 바로 위 오른쪽의 외곽선 칩 "이건 넘어갈게"(44px 터치, accent 테두리)로 통일. 선택지 목록의 스크롤 영역 밖에 두어 연봉처럼 선택지가 많아도 항상 보인다. 320×568에서 MBTI·종교·연봉·자산·추천인 5개 질문 모두 칩이 뷰포트 안에 보이고 필수 질문에는 나타나지 않음을 확인.

C-11: 브라우저에서 음주 빈 선택 전송 비활성→선택 후 활성→흡연 전송 확인. 종교도 미선택 전송 비활성이며 명시적 건너뛰기만 다음 질문으로 진행. 렌더에서 답변 버블/선택 답변/화살표 전송의 분리 확인. 5개 선택형 질문의 빈 선택 차단 회귀 검사 통과.

## 첫 화면 신청 흐름 (#15)
- 소개 문구를 '관심사가 통하는 지인의 지인과, 소개팅부터 소규모 모임까지'로 바꾸고, 복수 성별 버튼을 하나의 '찐친소 풀에 등록하기' CTA로 교체한다. CTA는 주선자 목록으로 이동한다.
- 성별 선택은 양쪽 주선자 채팅의 첫 말풍선 선택으로 옮긴다. 기존 `성별`의 여성/남성 값과 제출 필드는 그대로 사용한다.
- 소개 화면의 페이지 이동 컨트롤 위에 16px 안내 링크를 추가한다. 팝오버에는 요청된 등록 소개 문구와 소개팅·소규모 모임 각 5단계 진행 순서를 담는다. 소개팅의 간략 프로필 안내와 모임 비용(약 3-4만원)은 회색 보조문구로 구분한다.
- 이 변경 기록은 코드/화면 구조 확인 기준이다. 브라우저 크기별 배치와 팝오버 높이는 이번 작업에서 측정하지 않았다.
